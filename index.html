Frequently asked questions

Can I buy real medicine here?

No. This is an educational demo. No real order, prescription, or payment is processed.

Does the enquiry form send a message?

Only after a valid HTTPS form-service endpoint is configured. The starter code intentionally does not pretend that a demo message was delivered.

Is the listed store location real?

No verified pharmacy address has been provided. The map on the contact page is illustrative and is not a store pin.
